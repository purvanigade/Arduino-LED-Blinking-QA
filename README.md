
# Arduino LED Blinking – AI-Assisted QA Project

## Project Overview
This project demonstrates LED blinking using an Arduino Uno.

## Objective
To develop a basic embedded system and use AI tools and GitHub features for quality assurance, debugging, documentation and problem-solving.

## Components Required
- Arduino Uno
- LED
- 220-ohm resistor
- Breadboard
- Jumper wires

## Working
The Arduino controls an LED through digital pin 13.
The LED switches ON and OFF at one-second intervals.

## Programming Language
Arduino C/C++

## QA Activities
- Bug identification
- AI-assisted root cause analysis
- Code improvement
- GitHub Issues tracking
- Code review using pull requests

## Tools Used
- GitHub
- ChatGPT
- Arduino IDE / Wokwi

## Project Status
The Arduino LED blinking program has been improved using AI-assisted QA analysis. Four QA issues were documented, addressed, and closed through GitHub Issues.

The updated program was uploaded and tested successfully on Arduino Uno. LED initial state, blinking interval, pin configuration, and Serial Monitor output were verified.
